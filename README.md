# Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML5, CSS3, and JavaScript.

This portfolio showcases my skills, projects, resume, and contact information in a clean and user-friendly interface.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern dark user interface
- Smooth scrolling and animations
- Skills section
- Projects showcase
- Live Demo and GitHub project links
- Resume preview and download option
- Contact information
- Social media links
- Mobile responsive navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript
